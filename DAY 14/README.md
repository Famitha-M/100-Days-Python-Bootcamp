# Day 14 – Higher Lower Game

### 🎯 Goal
Build a **Higher Lower** game where the user guesses **who has more followers on Instagram**.

The program:
- Shows two celebrities/accounts with their follower counts hidden.
- Prompts the user to guess **who has more followers**.
- Increases the score for each correct guess and continues until the user guesses wrong.

---

### 🌐 Inspiration

### 🛠️ Key Concepts
- Importing and using **random** for selecting data.
- Using **while loops** to continue the game until a wrong guess.
- Creating and managing a **score system**.
- Working with **dictionaries** and **lists** to store account data.
