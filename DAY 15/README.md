# Day 15 – Coffee Machine

### 🎯 Goal
Build a Python program that simulates the working of a **coffee machine**.

The program should:
- Offer different drinks (e.g., espresso, latte, cappuccino).
- Check if there are enough resources (water, milk, coffee).
- Process coins and handle money transactions.
- Deduct resources after a successful purchase.

### 🛠️ Key Concepts
- Working with **functions** and **loops**.
- Handling **dictionaries** to store machine resources and menu items.
- Implementing **logic for transactions and resource management**.
- Simulating real-world scenarios with **user input** and **state updates**.
